# Sales Analyst Dashboard

Dashboard วิเคราะห์ยอดขายแบบ **Daily / MTD / YTD** พร้อมเทียบปีก่อน (YoY) — ทำงานเป็นเว็บ static ตัวเดียว (ไม่มี backend) ประมวลผล Excel ในเบราว์เซอร์ 100% ข้อมูลไม่ถูกส่งออกไปที่ใด

## วิธีใช้
1. เปิด `index.html` (หรือ deploy ทั้งโฟลเดอร์บน GitHub Pages / Netlify / Vercel)
2. Export ข้อมูลยอดขายจาก SharePoint เป็น `.xlsx` / `.xls` / `.csv`
3. กด **อัปโหลดไฟล์ยอดขาย** หรือลากไฟล์มาวาง
4. (ไม่บังคับ) กด **📦 อัปโหลดไฟล์สต็อก** เพื่อเปิดโมดูล Sell-Through/Weeks of Cover/ABC — ต้องอัปโหลดไฟล์ยอดขายก่อน
5. สลับมุมมอง Daily / MTD / YTD, กรองตามแบรนด์/ช่องทาง/ประเภทร้าน/หมวด/สาขา, กด **บันทึกรูป** เพื่อส่งรายงาน

ข้อมูลที่อัปโหลดล่าสุดจะถูกจำไว้ในเครื่อง (localStorage) เปิดครั้งหน้าไม่ต้องอัปใหม่

## คอลัมน์ที่ระบบอ่าน (จับคู่อัตโนมัติ)
ระบบจะหา sheet ที่มีคอลัมน์เหล่านี้ (ชื่อไทย/อังกฤษได้หลายแบบ):

| ข้อมูล | ชื่อคอลัมน์ที่รองรับ | จำเป็น |
|---|---|---|
| วันที่ขาย | `Sale_Date`, `Date`, `วันที่` | ✅ |
| ยอดขาย | `Netsale_ExcVAT` (แนะนำ) หรือ `Netsale_IncVAT` | ✅ |
| จำนวน | `Sold_Qty`, `Qty`, `จำนวน` | |
| ต้นทุน | `COGS`, `Cost` | |
| กำไร | `Margin_Value`, `GP` | |
| ช่องทาง | `Source`, `Channel` | |
| แบรนด์ | `Division Code`, `Brand`, `แบรนด์` | |
| หมวดสินค้า | `Product Subclass`, `Subclass` | |
| สาขา | `Store_Code` / `Store_Name` | |
| ประเภทร้าน | `Store.Type`, `Store_Type` | |
| รุ่นสินค้า | `ModelName`, `Model` | |
| เลขที่บิล | `Receipt_No` (ใช้นับจำนวนบิล — นับ Receipt_No ที่ไม่ซ้ำกัน) | |
| รหัส/ชื่อโปรโมชั่น | `Promotion_Code`, `Promotion_Name` | |
| ส่วนลด | `Discount_Value` | |

> ใช้ `Netsale_ExcVAT` (ไม่รวม VAT) เป็นตัวเลขยอดขายหลัก และ `Margin_Value` คำนวณ GP%
>
> แถวที่ `Source = STOCK` ในไฟล์ยอดขายจะถูกข้ามเสมอ ไม่นับรวมในยอดขาย (เป็นสแนปช็อตสต็อกแบบย่อ ไม่ใช่ธุรกรรมขาย) — dashboard จะแจ้งเตือนจำนวนแถวที่ข้ามให้ทราบ ใช้ **ไฟล์สต็อกแยก** (ด้านล่าง) แทนสำหรับโมดูลสต็อก

### ไฟล์สต็อก (Stock Card) — แยกจากไฟล์ยอดขาย
อัปโหลดผ่านปุ่ม **📦 อัปโหลดไฟล์สต็อก** เป็นสแนปช็อตสต็อก ณ วันที่หนึ่ง (เช่น "StockCard_06.09.2026.xlsx") ต้องมีคอลัมน์:

| ข้อมูล | ชื่อคอลัมน์ที่รองรับ | จำเป็น |
|---|---|---|
| วันที่สแนปช็อต | `Stock_Date` (รูปแบบ `DD/MM/YYYY` เป็นข้อความ) | ✅ |
| สาขา/คลัง | `Store`, `Store_Code` | ✅ |
| รหัสสินค้า | `GDNO`, `SKU` | ✅ |
| จำนวนคงเหลือ | `Stock available Qty` | ✅ |
| รุ่นสินค้า, แบรนด์, หมวดสินค้า | `ModelName`, `Division Code`, `Product Subclass` | |
| ต้นทุน/ราคาขาย/มูลค่าสต็อก | `Cost/Unit`, `Retail Price`, `Stock Amount (Current Price)`, `Cost Amount` | |

**เมื่ออัปโหลดไฟล์สต็อกที่มีแบรนด์ NATGEO และ/หรือ GOODR ระบบจะตั้งตัวกรองแบรนด์เป็น NATGEO + GOODR ให้อัตโนมัติ** (ใช้ร่วมกับตัวกรองแบรนด์หลักด้านบน จึงกรองทั้งยอดขายและสต็อกพร้อมกัน) — เปลี่ยนแบรนด์หรือเลือกหลายแบรนด์ได้ทุกเมื่อที่ตัวกรอง "แบรนด์"

## ตัวกรอง (เลือกได้หลายรายการ — Multi-select)
กรองข้อมูลทั้ง dashboard พร้อมกันได้จาก: **แบรนด์**, **ช่องทาง**, **ประเภทร้าน (Store Type)**, **หมวดสินค้า (Subclass)**, **สาขา** — แต่ละช่องมีช่องค้นหาในตัว (มีประโยชน์มากสำหรับรายชื่อสาขาที่มีหลายสิบสาขา) และปุ่ม "เลือกทั้งหมด/ไม่เลือกเลย"

## ตัวชี้วัดที่แสดง
- ยอดขาย, จำนวนชิ้น, GP (บาท) + GP%, ASP (ราคาขายเฉลี่ย/ชิ้น), จำนวนบิล, ยอดเฉลี่ย/บิล, COGS
- **เทียบปีก่อน (YoY)** ทุกตัวชี้วัด เสมอ และ **เทียบเดือนก่อน (MoM)** เพิ่มในมุมมอง Daily/MTD (จำนวนวันเท่ากัน เช่น MTD ถึงวันที่ 6 เทียบกับเดือนก่อนถึงวันที่ 6 เช่นกัน) — มุมมอง YTD ไม่มี MoM เพราะไม่มีนิยามที่เป็นมาตรฐาน
- กราฟแนวโน้ม (รายวัน 30 วัน / สะสม MTD vs LY / รายเดือน YTD vs LY)
- สัดส่วนช่องทาง, ยอดขายตามหมวด (Subclass), ตาราง Top 20 รุ่นสินค้า (พร้อม GP% และ YoY รายรุ่น)
- **🎯 Promotion Tracking** — ตามแท็บ Daily/MTD/YTD และตัวกรองด้านบนเหมือนกับ Top สินค้า:
  - สรุป: ยอดขายที่มี/ไม่มีโปรโมชั่น (และสัดส่วน %), ส่วนลดรวม, ส่วนลดเฉลี่ย % (เทียบยอดก่อนหักส่วนลด), จำนวนโปรโมชั่นที่มียอดขายในช่วงที่เลือก
  - ตาราง Top 15 โปรโมชั่น (ตามยอดขาย) พร้อมยอดขาย/ชิ้น/บิล/ส่วนลดรวม/ส่วนลด %/สัดส่วน/YoY ต่อโปรโมชั่น
- **ยอดขายและ Retail KPI รายสาขา** — ไม่ขึ้นกับแท็บ Daily/MTD/YTD เพราะเป็นตัวชี้วัดรายเดือนอยู่แล้ว ประกอบด้วย 2 ตาราง:
  1. **สรุปโดยรวม และตามประเภทร้าน** — แถวแรก "รวมทั้งหมด (Total)" ตามด้วยยอดสรุปของแต่ละ Store Type (Shop, SIS, ECOM, Event, Outlet, REV, WHS ฯลฯ)
  2. **รายละเอียดตามสาขา** — ตารางเดิม แยกทีละสาขา

  ทั้งสองตารางแสดงตัวชี้วัดเดียวกัน:
  - **ATV** (Average Transaction Value) = ยอดขาย ÷ จำนวนบิล
  - **UPT** (Units Per Transaction) = จำนวนชิ้น ÷ จำนวนบิล
  - **ASP** (Average Selling Price) = ยอดขาย ÷ จำนวนชิ้น
  - **Bill count** = จำนวนบิล (นับจาก Receipt_No ที่ไม่ซ้ำกัน)
  - **ยอด/วัน** = ยอดขายสะสมเดือนนี้ ÷ จำนวนวันที่ผ่านมาในเดือน
  - **พยากรณ์สิ้นเดือน** = ยอด/วัน × จำนวนวันทั้งหมดในเดือน (run-rate forecast)
  - **MoM / YoY** = % เปลี่ยนแปลงของยอดขาย MTD เทียบกับเดือนก่อน/ปีก่อนที่จำนวนวันสะสมเท่ากัน
- **📦 Stock & Sell-Through** (ต้องอัปโหลดไฟล์สต็อกเพิ่ม) — คำนวณ ณ วันที่สแนปช็อตสต็อก ไม่ขึ้นกับแท็บ Daily/MTD/YTD แต่ขึ้นกับตัวกรองแบรนด์/หมวด/สาขาด้านบน จับคู่ยอดขายกับสต็อกด้วยชื่อรุ่นสินค้า (ModelName):
  - สรุป: สต็อกคงเหลือ (ชิ้น/SKU/สาขา), มูลค่าสต็อก (ราคาขาย + ต้นทุน พร้อม GP ถ้าขายหมด), Sell-Through เฉลี่ย
  - **Stock, Stock Cost และ MOH รายสาขา** — ตาราง Total + แยกทีละสาขา: Stock คงเหลือ (ชิ้น), Stock Cost (มูลค่าต้นทุน), ยอดขายเฉลี่ย/เดือน, และ **MOH (Months On Hand)** = Stock ÷ ยอดขายเฉลี่ย/เดือน (จากยอดขาย 90 วันล่าสุด ÷ 3) — เห็นชัดว่าสาขาไหนสต็อกจมนานหลายเดือน (MOH สูง) หรือใกล้จะขายหมด (MOH ต่ำ)
  - **ABC Analysis** ตามมูลค่าขายสะสม 90 วันล่าสุด (Pareto: A = สะสมถึง 80% ของยอดขาย, B = ถัดไปถึง 95%, C = ที่เหลือ) — โชว์จำนวนรุ่น, % ยอดขาย, และมูลค่าสต็อกที่ผูกอยู่ในแต่ละคลาส (ช่วยเห็นว่าเงินทุนจมอยู่กับสินค้าขายช้าเท่าไร)
  - **รายการสินค้าต้องจับตา**: 🔴 ใกล้หมด (Weeks of Cover < 2 สัปดาห์ และยังมียอดขาย) และ 🟡 ขายช้า/ค้างสต็อก (Weeks of Cover > 12 สัปดาห์ หรือไม่มียอดขายใน 56 วันล่าสุด)
  - ตารางรายละเอียดสต็อกทั้งหมด (เรียงตามมูลค่าสต็อก) พร้อม ABC class, สถานะ, Sell-Through %, ยอดขายเฉลี่ย/สัปดาห์, Weeks of Cover ต่อรุ่นสินค้า
  - นิยาม: **Sell-Through %** = ขาย 90 วันล่าสุด ÷ (ขาย 90 วันล่าสุด + สต็อกคงเหลือ) • **Weeks of Cover** = สต็อกคงเหลือ ÷ ยอดขายเฉลี่ย/สัปดาห์ (เฉลี่ยจาก 8 สัปดาห์ล่าสุด)

## 🎯 Operation Target รายสาขา (Monthly Target)
1. กด **📄 ดาวน์โหลด Template เป้าหมาย** — ได้ไฟล์ `.xlsx` ที่มีรายชื่อสาขาทั้งหมดจากไฟล์ยอดขายที่อัปโหลดไว้แล้ว (คอลัมน์ `Store_Code`, `Store_Name`) พร้อมคอลัมน์เดือน `YYYY-MM` ครบ 12 เดือนของปีปัจจุบัน ให้กรอกตัวเลขเป้าหมายลงในช่องเดือนที่ต้องการ (เว้นว่างไว้ได้สำหรับสาขา/เดือนที่ยังไม่ตั้งเป้า)
2. กด **🎯 อัปโหลดไฟล์เป้าหมาย** เลือกไฟล์ที่กรอกแล้ว — รองรับคอลัมน์เดือนแบบ `YYYY-MM` กี่คอลัมน์/กี่ปีก็ได้ ไม่ต้องตรงกับ template เป๊ะ ขอแค่มีคอลัมน์ `Store_Code` และอย่างน้อย 1 คอลัมน์ชื่อ `YYYY-MM`
3. เป้าหมายของ**เดือนตาม "ณ วันที่" ปัจจุบัน**จะไปแสดงในตาราง Retail KPI รายสาขา (ทั้งสรุปรวม/ตามประเภทร้าน และรายละเอียดรายสาขา) เป็น 2 คอลัมน์ท้ายตาราง: **เป้าหมาย (เดือนนี้)** และ **% เป้าหมาย** (= ยอดขาย MTD ÷ เป้าหมาย) — สาขาที่ไม่มีเป้าหมายในไฟล์จะแสดง "—" แทน 0% เพื่อไม่ให้เข้าใจผิด

## Roadmap

- ✅ เฟส 3: โมดูลสต็อก (Sell-Through, Weeks of Cover, alert สินค้าใกล้หมด/ขายช้า, ABC Analysis, Stock/Stock Cost/MOH รายสาขา) — อัปโหลดไฟล์ Stock Card แยก
- ⏳ เฟส 4: ดึงข้อมูลอัตโนมัติจาก SharePoint (Microsoft Graph API)
